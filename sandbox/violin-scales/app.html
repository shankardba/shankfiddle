Violin Scale Bugs

Each key has its own beginner fingering — one string per tetrachord, some starting open, some not. Wherever the half step lands between two actual fingers, there's a bug; each finger-pair has its own.

D and E would need a position shift to complete a second octave in first position, so they stay one octave for now.
